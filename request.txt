PROJECT SPECIFICATION: SMART TOEIC EDGE AI APP & HUB (UPDATED)
1. OVERVIEW (UPDATED)
Build a static web application hosted on GitHub Pages acting as an "App Hub" for English learners.

Architecture: A Main Dashboard with routing to multiple sub-applications.

Core Apps: 1.  Daily TOEIC: Vocabulary learning with AI pronunciation check.
2.  Voice Invaders (Game): An interactive gamified experience using offline Speech-to-Text.

AI Core: Use Edge AI (Transformers.js) for offline Speech-to-Text (Whisper) and Semantic Search (MiniLM).

Tech Stack: Vite, React, Tailwind CSS, react-router-dom (HashRouter), @xenova/transformers.

4. NEW MODULE: GAME "VOICE INVADERS"

Concept: TOEIC words drop from the top of the screen to the bottom. The user must speak the word correctly to destroy it before it hits the bottom.

UI/UX:

Game Canvas/Area: Built with React state (or simple HTML5 Canvas) where word components slowly move down (using requestAnimationFrame or CSS animations).

Controls: A giant "Hold to Speak" button at the bottom.

HUD: Score counter, Lives (hearts), and Current Streak.

Logic & AI Integration:

Reuse Web Worker: Use the existing src/worker/speechWorker.js (Whisper-tiny).

Mechanic: When the user speaks, the transcribed text is compared (using Levenshtein distance) against the lowest currently falling word.

Action: If similarity > 80%, the word explodes (CSS animation), score +10. If the word hits the bottom, Lives -1.

Data Source: Randomly pick words from daily-vocab.json or a larger static JSON bank.
